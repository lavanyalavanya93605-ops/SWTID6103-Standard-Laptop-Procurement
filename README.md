**Team ID:** SWTID-2026-6103

**Members:** NASIMA J, DIVYADHARSHINI M, DEVADHARSHINI S

## Project Description
This project automates the Standard Laptop procurement process using ServiceNow Flow Designer. When a user requests a laptop via Service Catalog, the flow automatically creates a Catalog Task "Laptop needs to be Configured" and assigns it to the Hardware group.
